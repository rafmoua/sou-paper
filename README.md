# Empowering Bayes with sources of uncertainty

Code accompanying the paper

**Empowering Bayes with sources of uncertainty: from confidence modelling to sparse estimation**  
Rafael Mouallem Rosa, Julyan Arbel, and Hien Duy Nguyen.

The repository contains the estimators and experiment scripts used for the numerical results in the paper and Supplementary Material.

## Structure

- `sou/models/` — SoU-SGL estimators, Horseshoe baselines, and Bayesian neural-network modules.
- `sou/data/` — simulation definitions used in the linear-regression experiments.
- `scripts/data/` — MNIST download and linear-regression data generation.
- `scripts/runs/` — experiment runners.
- `scripts/analysis/` — scripts producing the figures and tables from saved results.

`data/`, `results/`, and `figures/` are generated locally and are not versioned.

## Installation

The reproducibility environment uses Python 3.11. A pinned Python environment is provided in `requirements-reproduce.txt`:

```bash
pip install -r requirements-reproduce.txt
pip install -e .
```

For Horseshoe experiments, R and `rstan` are also required. The environment used for these runs was R 4.3.3 with `rstan==2.32.6`, `StanHeaders==2.32.10`, `Rcpp==1.0.14`, `RcppEigen==0.3.4.0.2`, and `BH==1.87.0.1`.

## Fixed paper specifications

The run scripts encode the numerical specifications used in the paper directly. Hyperparameters and algorithmic initialisations used for the reported results are intentionally not exposed as tuning arguments.

For linear regression, SoU-SGL uses

- `lambda_tau = 10`, `lambda_nu = 1000`;
- `gamma_tau = 1e-9`, with the remaining confidence parameters equal to one;
- initial expected local precision `E[tau_j^{-2}] = 1e-2`;
- initial expected global precision `E[nu^{-2}] = 1`;
- tolerance `1e-3` and at most `10000` fixed-point iterations.

For MNIST logistic regression, GL and SoU-SGL share `lambda_tau = 10`, `lambda_nu = 1000`, the same initial local/global precisions (`1e-2` and `1`), tolerance `1e-3`, and at most `10000` iterations. They differ only in the local confidence (`gamma_tau = 1` for GL and `gamma_tau = 1e-6` for SoU-SGL). The intercept prior has standard deviation 10.

## Linear-regression experiments

The public scripts use the same experiment numbering as the paper:

- **Experiment 1** — main-text coefficient design based on `(1,2,...,10)`;
- **Experiment 2** — supplementary alternative design based on `(2,2,2,2,2,2,2,2,5,20)`;
- **Experiment 3** — heavy-tailed `t_2` signals with Bernoulli sparsity.

Generate the 100 simulation replicates used in the paper with

```bash
python scripts/data/generate_linear_regression_datasets.py
```

A single scenario can then be run, for example,

```bash
python scripts/runs/linear_regression/run_lasso.py --experiment 1 --spec 4 --rep 20 --save-coef
python scripts/runs/linear_regression/run_hs.py    --experiment 1 --spec 4 --rep 20 --save-coef
python scripts/runs/linear_regression/run_sou.py   --experiment 1 --spec 4 --rep 20 --save-coef
```

Summary tables for all three experiments are generated by

```bash
python scripts/analysis/linear_regression/tab_experiments_summary.py
```

and Figure 4 by

```bash
python scripts/analysis/linear_regression/fig_zero_coefficients.py
```

## MNIST logistic regression

Download/cache MNIST first:

```bash
python scripts/data/download_mnist_openml.py
```

The paper uses ten one-vs-rest fits. For digit `d`:

```bash
python scripts/runs/logistic_regression/run_mnist_ovr_digit.py --digit d
```

The runner fits LR, LR-L1, GL, and SoU-SGL using the same 60,000/10,000 split as the paper. Pixels are divided by 255 and then standardised feature-wise using the training-set mean and standard deviation.

Generate Table 2 and Figure 5 with

```bash
python scripts/analysis/logistic_regression/tab_summary.py
python scripts/analysis/logistic_regression/fig_coefficients_heatmap.py
```

## Normal means

The Normal-means experiment (Figure 3) is reproduced with

```bash
python scripts/runs/normal_means/run_normal_means.py
python scripts/analysis/normal_means/fig_kappa_panels.py --npz results/normal_means/runs/kappa_samples.npz
```

The shrinkage factor used in the experiment is

`kappa_i = 1 / (1 + n * tau_i^2 * nu^2 / sigma^2)`,

with `n = 5` replicates per coordinate.

## Bayesian neural networks

The BNN code follows the BBVI implementation used in the paper. The main MNIST training-dynamics comparison uses two hidden layers with 200 units per layer; the architecture experiment additionally varies the initial width over `50, 100, 200, 400, 800, 1200, 1600`. The toy-regression experiment varies sample size and network width as reported in the paper.

Run scripts:

```text
scripts/runs/bnn/run_mnist_bnn.py
scripts/runs/bnn/run_toy1d_one.py
```

Analysis scripts:

```text
scripts/analysis/bnn/fig_mnist_training_dynamics.py
scripts/analysis/bnn/tab_mnist_active_nodes.py
scripts/analysis/bnn/fig_toy1d_prediction_sparsity.py
scripts/analysis/bnn/tab_toy1d_summary.py
```

## Reproduction driver

To regenerate tables and figures from existing run outputs:

```bash
python scripts/reproduce_all.py --mode analysis
```

To launch the complete experiment pipeline sequentially:

```bash
python scripts/reproduce_all.py --mode full
```

The full pipeline is computationally intensive. Use `--dry-run` to inspect the commands without executing them.
